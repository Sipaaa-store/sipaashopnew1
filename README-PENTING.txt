SIPAA SHOP V4 — ORDER TIKTOK OTOMATIS

HASIL AKHIR

CARA PASANG
1. Upload ZIP ini secara UTUH ke project Netlify sipaashop.my.id yang sama.
2. Tunggu sampai status deploy menjadi Published.
3. Buka: https://sipaashop.my.id/setup-pakasir.html
4. Tempel API Key milik project Pakasir "sipaaa-storee" dan masukkan password admin Sipaa Shop yang sudah digunakan sebelumnya.
5. Tekan "Simpan dan aktifkan".
6. Salin alamat webhook yang muncul.
7. Di Pakasir buka project sipaaa-storee -> Edit Project -> tempel alamat tersebut pada kolom Webhook URL -> Simpan.

PENTING
- Jangan membayar ulang transaksi percobaan lama.
- Hanya pesanan BARU yang dibuat setelah V4 dipasang yang tersimpan di server dan bisa diproses otomatis.
- API Key Pakasir disimpan di penyimpanan server Netlify, bukan di HTML publik.
- Jangan bagikan ZIP ini atau API Key kepada siapa pun.
